# Objeção: "vou pensar"

## Princípio

**NÃO pressionar.** Cliente que se sente pressionado não volta.

## Resposta padrão

> "Tranquilo. Qualquer coisa é só chamar aqui. Vou deixar o orçamento salvo no seu nome por uns dias, ok?"

## Variação se for cliente recorrente

> "Beleza! Já guardei aqui pra você. Quando decidir, é só mandar 'fechar' que eu já separo."

## NUNCA

- Insistir
- Perguntar "mas o que tá faltando pra fechar?"
- Oferecer desconto pra forçar venda
- Mandar "vou estar aguardando" (formal demais)
