# Orientações gerais de recomendação

## Antes de recomendar marca, sempre

- Identificar uso/aplicação ("é pra obra ou reforma pequena?")

- Identificar nível do cliente (construtor profissional vs leigo) — usar playbook adequado

- Confirmar orçamento aproximado antes de partir pra linha premium

- Se cliente já chegou pedindo marca específica → siga a marca solicitada

## Hierarquia de decisão

1. Resolver a necessidade real do cliente (técnica antes de comercial)

2. Margem da empresa (preferência por marcas com melhor giro)

## Quando NÃO sugerir marca

- Cliente pede comparação genérica ("qual cimento vocês têm?") → lista até 3 opções com preços, deixa ele escolher

- Cliente pergunta opinião técnica que sai do escopo (dosagem, voltagem) → escala pra vendedor humano

- Produto requer dimensionamento específico (caixa d'água, bomba, fio elétrico) → escala

## Combo "kit completo" só quando

- Cliente é leigo no produto (não sabe que precisa do complemento)

- Faz sentido técnico (produtos que se complementam: cimento + areia + brita; tinta + rolo + lixa)

- Cliente é construtor pedindo quantidade — então perguntar se quer levar o complementar

⚠️ Nunca empurrar kit pra venda incremental forçada quando o cliente sabe o que quer.
